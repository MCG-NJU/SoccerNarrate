## 📖 Overview

**SoccerNarrate** is a unified data, training, and evaluation framework for **real-time, event-grounded streaming soccer commentary** over untrimmed full-match broadcasts:

- **SoccerNarrate-Data**: A large-scale time-anchored dataset built from 436 full-match SoccerNet broadcasts (391 train / 45 eval) with word-level ASR alignment, context-aware LLM quality filtering, and phoneme-based player/team entity calibration.
- **Macro-Window Preference Alignment (MWPA)**: Aligns streaming video-language models with complete event-level semantics by applying DPO over causal multi-step rollouts from a shared streaming prefix, using same-match event-mismatched human commentaries as counterfactual hard negatives—while keeping second-level low-latency streaming inference unchanged.
- **SoccerNarrate-Eval**: An event-centric full-match benchmark based on temporally constrained event entailment (`Qwen3-235B` as LLM-as-a-Judge) over 14 key soccer event classes.

## 🛠️ Environment Setup

We maintain separate conda environments for **training (SFT / DPO)** and **streaming inference**, following the StreamingVLM setup.

```bash
git clone https://github.com/MCG-NJU/SoccerNarrate.git
cd SoccerNarrate/streaming-vlm

# 1. Environment for SFT & DPO training
bash scripts/env_sft.sh

# 2. Environment for streaming inference
bash scripts/env_infer.sh
```

- Activate `streamingvlm-sft` for **SFT** and **DPO (MWPA)** training.
- Activate `streamingvlm-infer` for **streaming inference**.
- Make sure `flash-attn` matches your local CUDA / PyTorch / Python version (see comments inside `scripts/env_sft.sh` and `scripts/env_infer.sh`).

## 📂 Data Format

Minimal sample files are provided under `data/` for quick sanity checks:

- `data/sft.jsonl`: Word-level time-anchored streaming SFT conversations (`video`, `video_start`, `video_end`, and `text_stream`).
- `data/dpo_cross_event_15s.jsonl`: Macro-window preference pairs containing `prefix_text_tokens`, `prefix_video_secs`, `chunk_video_secs`, `chosen_steps`, `rejected_steps`, and `meta.video_path`.

For full training and evaluation, download the full SFT and DPO annotations from 🤗 **[JiaZihan1/SoccerNarrate-Data](https://huggingface.co/datasets/JiaZihan1/SoccerNarrate-Data)** (`sft/` and `dpo/`), prepare the official SoccerNet match videos (`1_720p.mkv`, `2_720p.mkv`) and SoccerNet event labels (`Labels-v2.json`), and point `DATASET_PATH` to the downloaded files.

For official SoccerNet download/directory layout instructions and the full **SoccerNarrate-Data** & **MWPA/DPO** construction scripts, please see **[`data_pipeline/README.md`](data_pipeline/README.md)**.

## 🚀 Training

### 1. Streaming SFT Training

Activate the training environment (`conda activate streamingvlm-sft`) and launch SFT via `tools/multi_nodes.sh` (which runs `tools/sft_stage_1.sh` → `train.py` with DeepSpeed ZeRO-3):

```bash
cd streaming-vlm

export DATASET_PATH="$(pwd)/../data"
export TRAIN_DATASET_NAMES="sft.jsonl"              # replace with soccernet_train_with_seeks.jsonl for full run
export VALID_DATASET_NAMES="sft.jsonl"              # replace with soccernet_test_with_seeks.jsonl for full run
export PRETRAINED_MODEL_NAME_OR_PATH="mit-han-lab/StreamingVLM"
export OUTPUT_DIR="./checkpoints"
export GPUS_PER_NODE=8
export LEARNING_RATE=1e-5

bash tools/multi_nodes.sh
```

> **Multi-node training:** Edit the `IP_LIST` array in `streaming-vlm/tools/multi_nodes.sh` (the first IP is the master node; keep `127.0.0.1` for single-node training). Ensure passwordless SSH and consistent paths across all nodes.

### 2. Macro-Window Preference Alignment (DPO Training)

Starting from the SFT checkpoint, run MWPA (DPO) via `tools/multi_nodes_dpo.sh` (which runs `tools/dpo.sh` → `train_dpo.py`):

```bash
cd streaming-vlm

export DATASET_PATH="$(pwd)/../data"
export TRAIN_DATASET_NAMES="dpo_cross_event_15s.jsonl"
export PRETRAINED_MODEL_NAME_OR_PATH="/path/to/sft/checkpoint"
export REF_MODEL_NAME_OR_PATH="/path/to/sft/checkpoint"  # optional; defaults to PRETRAINED_MODEL_NAME_OR_PATH
export OUTPUT_DIR="./checkpoints"
export GPUS_PER_NODE=8
export LEARNING_RATE=1e-6
export BETA=0.1
export LENGTH_NORM=True
export INCLUDE_PREFIX_VIDEO=True

bash tools/multi_nodes_dpo.sh
```

<details>
<summary>Key DPO hyperparameters</summary>

- `BETA`: DPO temperature coefficient (default `0.1`).
- `LENGTH_NORM`: Whether to normalize macro-window log-probabilities by supervised token count (`True` / `False`).
- `INCLUDE_PREFIX_VIDEO`: Include prefix visual context before the preference window (`True`).
- `TEXT_SINK` / `TEXT_SLIDING_WINDOW`: Streaming KV-cache text sink and sliding window sizes (default `512` / `512`).

</details>

## ⚡ Inference

Model checkpoints are hosted on Hugging Face ([**SoccerNarrate-7B**](https://huggingface.co/JiaZihan1/SoccerNarrate-7B) for the full SFT+MWPA model and [**SoccerNarrate-7B-SFT**](https://huggingface.co/JiaZihan1/SoccerNarrate-7B-SFT) for the Stage 1+2 SFT checkpoint; see the [**MCG-NJU Collection**](https://huggingface.co/collections/MCG-NJU/soccernarrate-6b03e5ec4b39ad06088131d2)).

Activate the inference environment (`conda activate streamingvlm-infer`) and run single-process streaming inference:

### 1. Single-Video Demo Inference

```bash
python streaming-vlm/streaming_vlm/inference/inference.py \
  --model_path /path/to/soccernarrate/checkpoint \
  --video_path demo/Goal.mp4 \
  --output_dir output/Goal.vtt
```

### 2. SoccerNarrate-Eval Test-Set Inference

```bash
python streaming-vlm/streaming_vlm/inference/baseline_infer.py \
  --model_path /path/to/soccernarrate/checkpoint \
  --annos_root /path/to/SoccerNet/asr/annos/test \
  --video_root /path/to/SoccerNet/videos \
  --output_root streaming-vlm/streaming_vlm/inference/infer_test/soccernarrate/test
```

See **[`streaming-vlm/streaming_vlm/inference/README.md`](streaming-vlm/streaming_vlm/inference/README.md)** for full argument details.

## 📊 Evaluation (SoccerNarrate-Eval)

SoccerNarrate-Eval evaluates temporally constrained key-event grounding using **Qwen3-235B** as an OpenAI-compatible LLM-as-a-Judge.

### Step 1: Serve the LLM Judge

Deploy `Qwen3-235B-A22B-Instruct-2507` behind an OpenAI-compatible API endpoint (e.g., via vLLM or SGLang):

```bash
export QWEN_API_URL="http://localhost:8000/v1/chat/completions"
export QWEN_API_KEY="your_api_key"
export QWEN_MODEL="Qwen3-235B-A22B-Instruct-2507"
```

### Step 2: Run Event Entailment Evaluation

Run the evaluator over the generated `.vtt` directory from the repository root:

```bash
python eval/llm_as_a_judge/soccernet_vtt_event_mentions.py \
  --infer-root streaming-vlm/streaming_vlm/inference/infer_test/soccernarrate/test \
  --labels-root /path/to/SoccerNet-label \
  --window-seconds 30 \
  --stride-seconds 15 \
  --delta-seconds 15 \
  --num-workers 64 \
  --out-dir eval/llm_as_a_judge/results
```

### Evaluation Outputs

The script writes the following files under `--out-dir`:
- `sliding_window_event_mentions.jsonl`: Per-window LLM judge predictions and extracted evidence.
- `sliding_window_event_mentions_summary.json`: Aggregate metrics including `event_recall@delta`, `faithfulness_precision`, `temporal_precision`, and `temporal_f1` (both class-averaged and overall across the 14 evaluated event classes).
- `summary_index.json`: Cross-model summary index when evaluating multiple `--infer-roots`.
